# Endpoints

Each API operation is one method on `IdealPostcodes`. Operations are grouped by resource. Examples use the `ak_test` key and placeholder identifiers; replace them with your own before running.

## Address Search

- [`find_address`](https://docs.ideal-postcodes.co.uk/docs/sdks/python/endpoints/find-address): Find Address
- [`resolve_address`](https://docs.ideal-postcodes.co.uk/docs/sdks/python/endpoints/resolve-address): Resolve Address

## UK

- [`postcodes`](https://docs.ideal-postcodes.co.uk/docs/sdks/python/endpoints/postcodes): Lookup Postcode
- [`address_cleanse`](https://docs.ideal-postcodes.co.uk/docs/sdks/python/endpoints/address-cleanse): Cleanse Address
- [`addresses`](https://docs.ideal-postcodes.co.uk/docs/sdks/python/endpoints/addresses): Extract Addresses
